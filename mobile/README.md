# אפליקציית משכלנתא לנייד

אפליקציה אחת לאנדרואיד ולאייפון, בנויה עם [Capacitor](https://capacitorjs.com).
האפליקציה לא מכילה עותק של הפלטפורמה: היא פותחת את האתר עצמו (`https://mashkalanta.com`)
בתוך מסגרת של אפליקציה. לכן כל המחשבונים, האזור האישי, אזור היועץ והתשלום עובדים
בדיוק כמו בדפדפן, וכל שינוי שעולה לאתר מופיע מיד גם באפליקציה, בלי לעדכן גרסה בחנויות.

## מה יש בתיקייה

| נתיב | מה זה |
| --- | --- |
| `../capacitor.config.ts` | ההגדרות: כתובת האתר, שם האפליקציה, מזהה `com.mashkalanta.app` |
| `android/` | פרויקט אנדרואיד (Android Studio) |
| `ios/` | פרויקט אייפון (Xcode, עם Swift Package Manager, בלי CocoaPods) |
| `www/` | עמוד "אין חיבור לאינטרנט" שמוצג כשהאתר לא נטען |
| `resources/` | מקור האייקון ומסך הפתיחה |

## מה שונה באפליקציה לעומת הדפדפן

הכול נמצא באתר עצמו, ב-`src/lib/native-app/` (פועל רק בתוך האפליקציה; בדפדפן לא קורה כלום):

- **הורדת קבצים** (דוחות PDF, טבלאות CSV ואקסל, מסמכים מהתיק, צרופות): הקובץ נשמר בטלפון
  ונפתח בתוכנה המתאימה, ומשם אפשר לשמור או לשתף.
- **קישורים חיצוניים** (בנקים, בנק ישראל): נפתחים בדפדפן בתוך האפליקציה. עמוד התשלום של HYP
  נפתח בתוך האפליקציה כדי שהתשלום יחזור לאתר.
- **"בכרטיסייה חדשה"**: באפליקציה אין כרטיסיות, אז העמוד נפתח באותו מסך (למשל פגישת וידאו).
- **כפתור "חזרה" באנדרואיד**: סוגר חלון פתוח, אחרת חוזר עמוד אחורה.
- **כניסה עם Google**: גוגל חוסמת התחברות מתוך אפליקציה כזאת, אז הכניסה נפתחת בדפדפן של הטלפון
  וחוזרת לאפליקציה מחוברת. הפרטים ב-`src/lib/app-handoff.ts`.
- **מצלמה ומיקרופון**: לצילום מסמכים ולפגישות וידאו עם היועץ. הטלפון מבקש אישור בפעם הראשונה.

## בנייה

צריך פעם אחת `npm install` בתיקייה הראשית של הפרויקט. אחרי שינוי בהגדרות או בספריות:

```bash
npx cap sync
```

### אנדרואיד

- **בלי מחשב:** בכל PR שנוגע באפליקציה, GitHub בונה קובץ התקנה לבדיקה
  (Actions ← Mobile app ← `mashkalanta-android-debug`). מורידים את ה-APK לטלפון ומתקינים.
- **ב-Android Studio:** `npx cap open android`, ואז Run. לחנות: Build ← Generate Signed App Bundle.

### אייפון

צריך Mac עם Xcode 16 ומעלה.

```bash
npx cap open ios
```

ב-Xcode: בוחרים צוות (Signing & Capabilities), ואז Run לטלפון או Product ← Archive להעלאה ל-App Store.

### בדיקה מול שרת אחר

```bash
MOBILE_SITE_URL=https://<preview>.vercel.app npx cap sync
```

## פרסום בחנויות

- **Google Play:** חשבון מפתח (25$ חד-פעמי), Bundle חתום, מדיניות פרטיות (`/privacy`) וצילומי מסך.
- **App Store:** חשבון Apple Developer (99$ לשנה). Apple בודקת שהאפליקציה מוסיפה משהו מעבר לאתר;
  כאן זה צילום מסמכים, פגישות וידאו, פתיחת קבצים בטלפון וכניסה עם Google דרך המערכת.
  התראות פוש יחזקו את זה עוד, והן השלב הבא המתבקש.

## מגבלות ידועות

- קישורים מהמייל (אימות הרשמה, איפוס סיסמה) נפתחים בדפדפן של הטלפון ולא באפליקציה.
  אחרי האימות נכנסים לאפליקציה עם המייל והסיסמה. פתיחה ישירה באפליקציה (Universal Links)
  דורשת את מזהה הצוות של Apple ואת חתימת האפליקציה באנדרואיד.
- אין עדיין התראות פוש. זה דורש Firebase לאנדרואיד ומפתח APNs של Apple.
- הכניסה הנסתרת של היועץ נשארת בדפדפן, כמו היום.
