# ההדגמה הקצרה בדף הבית

הסרטון שנפתח מהכפתור "צפו בהדגמה קצרה" מתחת לאנימציה בדף הבית
(`public/promo/mashkalanta-promo.mp4`) מוקלט מהממשק האמיתי, עם נתונים לדוגמה בלבד,
בסדר הזה: הכלים החינמיים כאורח (היתכנות, בדיקת מיחזור, הלוואות צרכניות), ההרשמה
ותכנון הון עצמי מלא כרשום, האזור האישי (פעולות מהירות, מצב הון ותזרים, לוח שנה ומשימות,
תיק המסמכים, צ׳אט ומיילים), וחמשת שלבי התהליך עם הדוחות לבנק.

- **התסריט וההקלטה**: `record.mjs` — הכתוביות, הלחיצות וההקלדה כתובים בו, לפי הסדר.
  הוא מסתיר את פקדי ההדגמה, מציג כתוביות גדולות, כרטיסי פרק וכרטיס סיום, ומצלם.
  הפעולות מואצות פי `SPEED` (ברירת מחדל 2.8), ההקלדה פחות, זמן הקריאה של הכתוביות
  נשמר וזמן הטעינה בין מסכים נחתך.
- **הבמה לחלקים של הרשומים**: `src/demo/catalog/flows/promo.ts` — ההדגמה `promo` רצה
  מושהית כדי לקבל את האזור האישי עם נתוני ההדגמה. היא לא מוצגת למבקרים.
- **נתוני השוק**: `market-snapshot.json` — נתוני בנק ישראל כפי שהוצגו בדאשבורד
  בדף הבית ב-26.9.2026, כדי שההקלטה לא תלויה ברשת. כדאי לעדכן לפני הקלטה חדשה.

## הקלטה מחדש

```bash
npx next build && npx next start &          # האתר על http://localhost:3000
npm i --no-save playwright-core@1.56.1
node scripts/promo-video/record.mjs          # FFMPEG=/path/to/ffmpeg CHROMIUM=/path/to/chrome לפי הצורך
# ONLY=free או ONLY=reg מקליט רק חלק אחד, לכיוונון
```

התוצרים נכתבים ל-`public/promo/`: הסרטון, תמונת הפתיחה וקובץ הכתוביות (VTT).

## קריינות

`NARRATION=voice.mp3 node scripts/promo-video/record.mjs` משלב קובץ שמע בסרטון.
הזמנים של כל כתובית נמצאים ב-`public/promo/mashkalanta-promo.he.vtt`, ולפיהם מקליטים
או מפיקים את הקריינות.
