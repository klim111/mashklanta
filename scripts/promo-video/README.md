# ההדגמה הקצרה בדף הבית

הסרטון שנפתח מהכפתור "צפו בהדגמה קצרה" מתחת לאנימציה בדף הבית
(`public/promo/mashkalanta-promo.mp4`) מוקלט מהממשק האמיתי, עם נתונים לדוגמה בלבד.

המסך בנוי מפס כתוביות למעלה, ומתחתיו האתר עצמו ברוחב מסך מחשב מלא (iframe בתוך דף מסגרת
שהמקליט מגיש), כך שהכתוביות לא מסתירות אף חלק מהעמוד והעמוד נראה כולו. השקופיות מכסות את
כל המסך. הקטעים, בסדר הזה:

1. **intro** — שקופית החזון עם המאזניים, ושקופית "כל המשכנתא במקום אחד" עם הסערה.
2. **free** — הכלים החינמיים כאורח: מה אני יכול להרשות לעצמי (הקלדה, הזזת ערכים ונעילה),
   בדיקת מיחזור והלוואות צרכניות. בסופו שקופית ההצטרפות (אנימציה של הקהילה שמאזנת את
   המאזניים, ומה מקבלים הרשומים).
3. **dash** — "ניהול כל תהליך המשכנתא במקום אחד": הלשוניות של האזור האישי, הכפתור הצף,
   המחשבון המהיר והכלים.
4. **equity** — תכנון הון עצמי עם 11 שורות, לוח שנה והדוח הסופי.
5. **docs** — "ניהול כל המסמכים במקום אחד", ו"תקשורת עם כל הגורמים בעסקה" (צ׳אט ומיילים,
   כולל עורך דין ושמאי).
6. **call** — שיחת וידאו עם היועץ: שיתוף מסך, הצגת מסמך לשני הצדדים ושליחה בצ׳אט
   (`/demo/meeting`, מסך השיחה בלי חדר LiveKit אמיתי).
7. **forms** — "כל הטפסים ממולאים אוטומטית": כתב הסמכה ליועץ ממולא ונחתם, והטופס של לאומי
   מתמלא על המסך (`pdf-page.py` הופך את ה-PDF לתמונה).
8. **plan** — חמשת השלבים מ-1 עד 5, כולל דוח הפרופיל, בניית תמהיל, גרפים, השוואה בין
   תמהילים, לוח סילוקין, פרעון מוקדם וההצעה לבנקים; ובסוף שקופית "יש לכם משכנתא מותאמת
   אישית" עם החוטים.
9. **mine** — "המשכנתא שלי" אחרי החתימה, וכרטיס הסיום.

האנימציות של השקופיות מוגשות מ-`/video-stage?slide=balance|storm|threads` (דף שאינו
מקושר מהאתר).

- **התסריט וההקלטה**: `record.mjs` — הכתוביות, הלחיצות, הגרירות וההקלדה כתובים בו, לפי
  הסדר. הוא מסתיר את פקדי ההדגמה, מציג את הכתוביות בפס שמעל האתר, את השקופיות וכרטיס
  הסיום, ומצלם.
  הפעולות מואצות פי `SPEED` (ברירת מחדל 1.6, קצב של סרטון רגיל), ההקלדה והגרירה פחות,
  זמן הקריאה של הכתוביות נשמר וזמן הטעינה בין מסכים נחתך.
- **מעברים רכים**: `soften.py` (Python עם Pillow) — בכל מעבר מסך (טעינה, לשונית, חלון,
  שלב) מכניס מעבר הדרגתי במקום קפיצה. בלי Pillow הסרטון יוצא עם חיתוכים רגילים.
- **הבמה לקטעים של הרשומים**: `src/demo/catalog/flows/promo.ts` — ההדגמה `promo` רצה
  מושהית כדי לקבל את האזור האישי עם נתוני ההדגמה. היא לא מוצגת למבקרים.
- **נתוני השוק**: `market-snapshot.json` — נתוני בנק ישראל כפי שהוצגו בדאשבורד
  בדף הבית ב-26.9.2026, כדי שההקלטה לא תלויה ברשת. כדאי לעדכן לפני הקלטה חדשה.

## הקלטה מחדש

```bash
npx next build && npx next start &          # האתר על http://localhost:3000 (לא next dev)
npm i --no-save playwright-core@1.56.1
python3 -m pip install pillow pymupdf       # המעברים הרכים, והטופס שמתמלא
node scripts/promo-video/record.mjs          # FFMPEG=/path/to/ffmpeg CHROMIUM=/path/to/chrome לפי הצורך
# ONLY=free,plan מקליט רק חלק מהקטעים (forms לפני call, כי בשיחה מוצג הטופס), SKIP_WEBM=1 מדלג על עותק ה-WebM — לכיוונון
```

התוצרים נכתבים ל-`public/promo/`: הסרטון (MP4 ו-WebM), תמונת הפתיחה וקובץ הכתוביות (VTT).
אחרי הקלטה צריך להפעיל מחדש את `next start` כדי שהקבצים החדשים יוגשו.

## קריינות

`NARRATION=voice.mp3 node scripts/promo-video/record.mjs` משלב קובץ שמע בסרטון.
הזמנים של כל כתובית נמצאים ב-`public/promo/mashkalanta-promo.he.vtt`, ולפיהם מקליטים
או מפיקים את הקריינות.
