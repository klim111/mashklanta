# מצב ההדגמה (Demo Mode)

הדגמה אינטראקטיבית שרצה על הממשק **האמיתי** של משכלנתא — אותם דפים, רכיבים,
מחשבונים וגרפים — עם נתונים בדויים ובלי לגעת בשום דבר אמיתי.

## איך זה עובד

```
src/demo/
├── store.ts                 # החנות הקטנה: איזו הדגמה פעילה (הדבר היחיד שהאתר הרגיל טוען)
├── DemoHost.tsx             # יושב בשורש (providers.tsx); טוען את זמן הריצה בעצלות
├── DemoRuntime.tsx          # מתקין את ארגז החול, מריץ את המנוע ומצייר את השכבה
├── sandbox/                 # ארגז החול
│   ├── api-router.ts        #   שרת מדומה בזיכרון — עונה לכל /api/* (כתיבות נשארות בזיכרון)
│   ├── fetch-shim.ts        #   יירוט fetch / XHR / sendBeacon
│   └── storage-shim.ts      #   localStorage/sessionStorage מבודדים
├── data/
│   ├── demo-session.ts      # הפרסונה וה-session המדומה (קובץ קל, לספקי השורש)
│   └── demo-data.ts         # כל נתוני ההדגמה במקום אחד — ערכי המחשבונים, משימות, פגישות, תמהילים
├── engine/
│   ├── DemoEngineProvider   # מכונת המצבים: playing / paused / user-control / resumed / completed
│   ├── actions.ts           # לחיצה, הקלדה, סליידר, בחירה, גלילה, הארה — על ה-DOM האמיתי
│   ├── spotlight.ts         # driver.js (הארה + חלונית הסבר, RTL)
│   ├── narration.ts         # ממשק קריינות (כתוביות היום; קול בעתיד)
│   └── text.ts              # תבניות כתוביות {{key|money}}
├── ui/                      # הסרגל התחתון, הסמן הווירטואלי, מצב ההתנסות, מסך הסיום
├── catalog/
│   ├── index.ts             # הקטלוג: id, כותרת, תיאור, אייקון, מסך, קטגוריה, סדר
│   └── flows/*.ts           # הצעדים של כל הדגמה (נטענים בעצלות)
└── components/              # הכפתור בדף הבית, כרטיסי ההדגמות, שער מסכי ההדגמה
```

- **הרכיבים מסומנים ב-`data-demo-id`** (דרך `demoId('...')` מ-`demo-attr.ts`), לא בסלקטורים של CSS.
- **מסכים שדורשים חשבון** (האזור האישי, שולחן העבודה של התהליך) חיים תחת `/demo/dashboard`
  ו-`/demo/plan`, כי `/dashboard/*` חסום במידלוור למי שאינו מחובר. הכלים הציבוריים רצים במסלול
  האמיתי שלהם, בתוך ארגז החול.
- **המצב שורד ניווט**: המנוע יושב בשורש, והבקשה נשמרת ב-sessionStorage המקורי — רענון ממשיך
  מאותו צעד.
- **"עצרו ונסו בעצמכם"**: כל צעד עם `allowTryIt` מציע שליטה למשתמש; בחזרה המנוע קורא מהמסך את
  הערכים שהשתנו (`readUserValues`) ומסמן אותם כ-`userSet`, כך שהצעדים הבאים לא דורסים אותם והכתוביות
  משתמשות בהם.

## הוספת הדגמה חדשה

1. סמנו את הרכיבים בכלי: `{...demoId('my-tool-price')}`.
2. צרו `catalog/flows/my-tool.ts` שמייצא `DemoFlow` עם צעדים.
3. הוסיפו רשומה ל-`DEMO_CATALOG` ב-`catalog/index.ts` (עם `featured: true` כדי שתופיע בדף הבית).
4. `npx vitest run src/demo` — הבדיקה מוודאת שהקטלוג והצעדים תקינים.

## ערכי ההדגמה

כל המספרים (הכנסה, הון עצמי, מחיר נכס, משימות, פגישות...) נמצאים ב-`data/demo-data.ts`
(`DEMO_INPUTS`) ובקבצי הצעדים. שינוי שם משנה את כל ההדגמות.
