# מודול ההלוואות הצרכניות וכלכלת המשפחה

הכלי בנוי באותו קונספט של בונה התמהילים וכלי המיחזור: **פאנל שליטה** שבו כל
פרמטר הוא מכוון, ו**דאשבורד** שמתעדכן חי מולו — בלי שמירה ובלי מעבר מסך.

הדף זמין בכתובת `/consumer-loans`, פתוח גם למי שאינו רשום, וכל הנתונים נשמרים
ב-localStorage של הדפדפן בלבד.

## חלקי הכלי

### 1. ההלוואות שלי — פאנל שליטה + דאשבורד
- כרטיס לכל הלוואה: שם, סוג (בנקאית, אשראי, רכב, משפחה, אחר), ומכוונים לקרן,
  לריבית השנתית ולתקופה. הוספה, שכפול ומחיקה.
- דאשבורד: סך החוב, ההחזר החודשי, סך הריבית, הריבית המשוקללת וסיום התשלומים;
  פס הרכב התיק (לחיצה על מקטע מסמנת הלוואה להשוואה); יחס ההחזר מההכנסה מול
  תקרת בנק ישראל; תובנות; וגרף החוב לאורך הזמן.

### 2. השוואה ותרחישים
- סיכום משווה של ההלוואות שסומנו, ומתחתיו תרחיש עם ההפרש בכל סעיף.
- **איחוד הלוואות**: ריבית ותקופה כמכוונים, מול המצב הקיים.
- **פירעון מוקדם**: הפניית מזומן להלוואה היקרה (אוולנץ׳) והחיסכון שהיא מייצרת.
- **גרפים**: השוואת החזר/ריבית/תשלום, וקצב ירידת היתרה של כל הלוואה.

### 3. אסטרטגיה — שילובים ואופטימיזציה
מזומן זמין, הוצאה צפויה, ריבית להלוואה חדשה, תקרת החזר ומטרה (מינימום ריבית או
מינימום החזר חודשי) → כל התרחישים נבדקים (`optimizer.ts`) והמוביל מוצג מול המצב
הקיים, עם הרכב התוכנית, חלוקת המזומן וטבלת התרחישים.

### 4. לוח סילוקין
מודאל לכל הלוואה: גרף ירידת הקרן והריבית המצטברת, בדיקת פירעון מוקדם בחודש
נבחר, טבלת תשלומים מלאה וייצוא ל-CSV.

### 5. פנייה ליועץ כלכלת המשפחה
כפתור צף בפינה השמאלית התחתונה. הפנייה נשלחת ל-`/api/advisor-leads` בנושא
`FAMILY_ECONOMY` ומופיעה אצל היועצים כבקשת ליווי, יחד עם תמונת התיק שהלקוח הזין.
לקוח שאינו רשום מזין שם וטלפון; המייל רשות.

## נוסחאות מתמטיות

### תשלום חודשי (אנונה)
```
r = annualRatePct / 100 / 12
אם |r| < 1e-12: payment = P / n
אחרת: payment = P * r * (1+r)^n / ((1+r)^n - 1)
```

### פרעון מוקדם (מצב reduce)
לאחר הפחתת הקרן, מחושב תשלום חדש:
```
paymentNew = annuityPayment(balanceNew, apr, remainingMonths)
```

### פוטנציאל האיחוד שמוצג ליד ההזמנה ליועץ
הנחה מוצהרת: ריבית נמוכה בשתי נקודות מהריבית המשוקללת של התיק (ולא מתחת ל-5%),
לתקופה הממוצעת המשוקללת שמשולמת היום. ראו `savingsPotential` ב-`loanInsights.ts`.

## קבצי המודול

- `types.ts` — טיפוסים (כולל `LoanCategory` וההכנסה החודשית)
- `loanMath.ts` — אנונה, לוח סילוקין, יתרה ופירעון מוקדם
- `optimizer.ts` — אוולנץ׳, תרחישי איחוד ובחירת התוכנית המובילה
- `loanInsights.ts` — נתוני התיק, סדרות לגרפים, יחס החזר ותובנות
- `LoanWorkspace.tsx` — הקומפוננטה הראשית: מסך אחד עם פאנל שליטה ודאשבורד.
  לשוניות "איחוד" ו"אסטרטגיה" נוצרות רק כשהלקוח בוחר בהן, ונעלמות כשמסירים אותן
- `LoanFields.tsx` — שורת פרמטר: תווית, שדה הזנה וסליידר בעמודות שוות, בלי ערך ברירת מחדל
- `LoanControlPanel.tsx` — פאנל השליטה (כרטיס לכל הלוואה, כולל פירעונות מוקדמים)
- `LoanPrepaymentDialog.tsx` — פירעון מוקדם מתשלום שהלקוח בוחר (קיצור תקופה או הקטנת החזר)
- `LoanPortfolioDashboard.tsx` — דאשבורד התיק (ריק עד שמזינים הלוואה)
- `LoanConsolidation.tsx` — בחירת ההלוואות לאיחוד, פאנל האיחוד והדאשבורד שלו
- `LoanStrategy.tsx` — מזומן זמין והוצאה צפויה: האסטרטגיה המובילה
- `ScenarioRow.tsx` — שורת "היום מול אחרי" המשותפת לאיחוד ולאסטרטגיה
- `RateInfoButton.tsx` — כפתור "!" ליד כל שדה ריבית: ריביות לפי מוסד מממן מבנק ישראל
- `ConsumerCreditMarket.tsx` — אזור נתוני השוק בתחתית העמוד (חוב, ריביות, מוסדות)
- `useConsumerCredit.ts` — טעינת נתוני בנק ישראל מ-`/api/boi/consumer-credit`
  (הנתונים נשלפים ב-`src/lib/boi-consumer-credit.ts`)
- `AmortTable.tsx` / `AmortChart.tsx` — לוח הסילוקין והגרף שלו
- `LoanPlanningImportWizard.tsx` — ייבוא ההלוואות מהפרופיל הפיננסי
- `FamilyEconomyAdvisor.tsx` — הכפתור הצף, כרטיס הערך וטופס הפנייה ליועץ
